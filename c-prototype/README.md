# 校准阅卷 · C 应用

本目录保留原型启动入口；业务实现位于项目根目录的 `c_app`，B 评分源码位于 `backend/grading`。详见 [C 交付与部署说明](../docs/C交付与部署说明.md)。

## 在 Windows 启动

以下命令均在仓库根目录执行：

```powershell
.\c-prototype\prepare.ps1
.\.venv\Scripts\python.exe -m c_app.cli bootstrap --username your-admin
.\.venv\Scripts\python.exe -m c_app.cli demo --username your-admin
.\.venv\Scripts\python.exe -m c_app.cli import-a --username your-admin
```

创建管理员时在终端交互设置至少 12 字符密码，不把密码写进命令历史。已有管理员时不要重复创建。首次 `import-a` 下载固定提交的公开 A 数据并保留来源和许可证，导入 15 题、1,582 份无分答案及 92 份未批准候选；不会请求模型或自动发布规则。重复导入时指定上次输出的 `--course-id` 可去重。

分别在两个终端启动网页与后台 Worker：

```powershell
.\.venv\Scripts\python.exe c-prototype/app.py
```

```powershell
.\.venv\Scripts\python.exe -m c_app.worker
```

访问 [本机工作台](http://127.0.0.1:18065)，用自己创建的管理员登录。端口冲突时可给网页入口增加 `--port 18066`。服务默认仅监听本机，不需要 Docker。

本次协作已在这台电脑初始化本机管理员，登录信息只保存在忽略上传的 `work/local-access.json`；它不是通用演示密码，也不是真实教师账号。新克隆不会携带此文件或数据库，需按上面步骤自行创建管理员。

## 从合成演示开始

1. 选择“合成流程演示”，勾选允许草案试验，选择本题三份答案并创建评分任务。
2. 切换“批量任务”，刷新后应看到两份已处理、一份模拟调用失败。空答案有待复核原因，没有默认零分。
3. 打开正常任务，核对建议分、逐项理由与原文。可以修改分项分数，选择原始答案中的文字并引用，填写逐项理由后保存试验复核。
4. 试验记录可以单独导出；正式成绩导出不包含这些数据。模拟失败只允许显式重试。

合成演示题和模型响应均为预先编写的回放，不能说明模型准确性或校准收益。A 的真实开发数据没有伪造回放评分，当前默认关闭真实模型。

## 教师与学生流程

管理员创建实际使用者的账号，并把教师、学生加入对应课程。教师在网页上建题、编辑规则草案；实际审核后另建正式版本。规则发布与成绩确认均记录当前登录账号和服务端时间。

答案导入采用 A 的无分 JSONL，每行只接受 `q_id`、`answer_id`、`answer`。题号必须匹配；同编号同文跳过，同编号异文整次回滚。参考分、总分标签不能混入模型输入。

教师可为答案分配本课程学生。模型建议经过逐项核对后确认；批准作为可复用案例须另行操作。仅教师审核且版本匹配的练习题进入推荐。学生只能看到分配给本人且教师已发布的当前版本结果与对应练习。

规则与案例集合都保留版本；历史依据不会被新版本静默覆盖。已有规则或答案的题目需另建题号修改。旧匿名 `/api/*` 和 `/export.csv` 接口已停用。

## 配置与数据库

默认新数据库：`work/application.sqlite3`。旧 `work/grading.sqlite3` 不会覆盖。可通过只读命令迁移历史资料：

```powershell
.\.venv\Scripts\python.exe -m c_app.cli import-legacy --username your-admin --course-id 2 --source "旧数据库绝对路径"
```

迁移记录标为旧原型、身份未核验，不进入正式成绩或案例库。旧工作区外同名副本保持不变。

进程使用服务端环境变量配置，**不会自动加载 `.env`**；容器 Compose 才读取本机 `.env`。支持 `DATABASE_URL`、可选 `REDIS_URL` 及 B 的 `GRADING_*` 设置。真实模型需额外开启 `C_ALLOW_LIVE=true`，并在网页中明确确认所选答案的外发与费用。当前交付不会自动调用模型。

本地源码、数据库和网页检查不等于真实教师审核、模型效果验收、CodeArts 使用记录或华为云部署成功。上云配置、备份恢复和云端检测清单见交付说明。
