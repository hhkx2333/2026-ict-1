# 评测、冻结配置与复现

更新：2026-11-15。当前第011题材料已用于开发，不称封存最终测试。

## 1. 不付费的完整流程

```sh
python3 -m unittest discover -s tests -v
python3 -m examples.integration_flow
python3 -m backend.grading.experiments --help
```

integration_flow为合成回放；不读取本机密钥，不发请求，不证明真实校准有效。

## 2. 冻结开发对照

experiments.freeze_plan接收固定question/rubric、严格无分ADS答案、方法列表和不含密钥的model_config。保存代码摘要、输入、规则、标签版本、可选标签摘要、总调用上限和plan_sha256。run_plan拒绝已修改计划、变化的评分代码、不同模型配置及已存在输出目录。计划不是签名或权限系统，C/A应控制谁能修改版本。

命令示意，路径替换为A提供的实际文件：

```sh
python3 -m backend.grading.experiments freeze --question question.json --rubric rubric.json --answers unscored.jsonl --model-config public-model-config.json --label-version LABEL_VERSION --truth truth.jsonl --output plan.json --modes direct structured checklist --allow-draft
python3 -m backend.grading.experiments run --plan plan.json --truth truth.jsonl --output new-run-directory --live
```

public-model-config包含endpoint/model/max_tokens/thinking四项，绝不含API key。--live明确触发向配置服务发送这一批答案并计费；实际运行前须取得数据外发授权及额度条件。该工具通用运行入口限制调用次数，不推断精确价格；本机真实实验脚本额外设置DeepSeek余额保留及显示支出上限。

direct每份1次请求，其他模式最多2次。direct与结构化路径提供相同题目、参考答案及通用细则；检查项路径另有结构检查/算法分析，因此额外提示与成本须单独解释。草案所有路径均保持人工复核。

calibrated路径需真实PUBLISHED规则及非空审核案例；未提供会在模型调用前失败，不用合成教师案例冒充实验。支持该路径不等于已经证明校准有效。人工原流程与人工时间由A组织记录。

评分全部结束后才加载参考分进行评测；冻结的可选标签摘要不进入模型。计划包含先前已明确的标签版本与摘要，不包含目标参考分。不得将MD里写着“某答案给几分”的个案标签整份输入模型。

## 3. 输出档案

每方法逐条JSONL及时落盘，保存plan.json、call_accounting.json、各方法summary及同ID配对比较。失败和未给分进入覆盖率分母，不当作0分，也不删除大分差答案。每个方法附-evidence-audit-tasks.json，供A组织语义审核。

总MAE、RMSE、偏差、容差、严重分差、低风险覆盖率与误差分别报告。另提供每参考样本的容差一致比例和归一化MAE。配对比较同时显示完整参考覆盖率与双方共同成功子集，不能只展示共同成功的小集合。

非同一批次或标签版本不同不能直接横比；即使同样本也要记录提示、模型、规则及案例输入差异。比较只是开发分数一致性，不能把所有参考分默认为教师真值。

## 4. 人工证据质量与耗时

引用精确存在由程序校验，语义支持需教师逐项审核。evidence_tasks带assessment_sha256；审核结果须绑定同一模型评分、填写teacher_confirmed/reviewer_id/verdict（SUPPORTED/UNSUPPORTED/UNCERTAIN）。没有人工审核时支持率为null，而非0或100%。旧评分审核不能静默移给新评分。

逐项质量需要真实teacher_confirmed的confirmed_items；只给总分时逐项MAE保持未知。人工时间记录event_id/reviewer_id/phase/seconds，phase为rule_preparation/calibration/review/spot_check/rework/manual_baseline；事件不能重复，不能省略校准工时后宣称省时。对照批次难度、交叉顺序和完整性仍由A控制，程序不会凭零散日志认定节省时间。

离线复算命令：

```sh
python3 -m backend.grading.cli evaluate --predictions predictions.jsonl --truth truth.jsonl --output metrics.json --compare-to baseline.jsonl --evidence-reviews reviewed.jsonl --time-logs time.jsonl
```

不具备的审核/时间文件参数应省略，不能为了让命令运行而造记录。更多字段约束见quality.py和examples/integration_contract.json。语义风险码缺失的严重分差仅是诊断；草案实际仍全部转教师，不能把诊断混称正式成绩漏放率。

## 5. 复现边界

源码包只包含源码、测试、合成示例与文档，不含.env、学生原始记录、.git或缓存。本地实验档案单独保存。新机器需配置自己的服务端密钥并取得数据授权；固定代码摘要不保证服务端模型权重、数值生成或平台限流永远一致。

不能事后编造CodeArts使用记录、云部署、教师批准、封存测试、工时或校准收益。当前工作只按真实运行与审核情况报告。
