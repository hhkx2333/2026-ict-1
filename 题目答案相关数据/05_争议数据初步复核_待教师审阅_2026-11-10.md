
## 四、069：建议6分，待教师确认

**完整原文：**

```text
使用栈S1和S2来模拟队列：先将所有元素入栈到S1，因为栈是后进的先出，所有顺序会是反过来的，因此需要将S1所有元素出栈再入栈到S2，从而得到正确的顺序，再在S2执行出栈，从而模拟队列。
入队：



bool EnterQueue(Stack S1,StackItem x)
{
    if(!StackFull(S1))
    {
        push(S,x);
        return true;
    }
    if(StackFull(S1)&&StackEmpty(S2))
    {
        while(!StackEmpty(S1))
        {
            pop(S1,t);
            push(S2,t);
        }
    }
    push(S1,x);
    return true;
}




出队：



bool DeleteQueue(Stack S1,Stack S2,StackItem x)
{
    if(!StackEmpty(S2))
    {
        pop(S2,x);
        return true;
    }
}




判断队列是否为空：



bool QueueEmpty(Stack S1,Stack S2)
{
    if(StackEmpty(S1)&&StackEmpty(S2))
    {
                    return true;
    }
    else
    {
                    return false;
    }
}
```

**可确认的缺失：**暂将push(S,x)中的S理解为S1，在S1未满时入队a，状态为S1=[a]、S2=[]。随后调用DeleteQueue，唯一的S2非空分支不执行，无法返回a。入队函数里的倒栈循环只在S1满且S2空时触发，不能补上这次出队缺失。

入队中还存在S1满且S2非空时继续执行末尾push(S1,x)的风险；既然学生主动写了容量分支，就要检查自洽性。本稿将其与未定义S共同计入入队不完整，不在其他项重复扣分。Stack类型未定义，不进一步武断推定传值语义或运行结果；本稿没有执行学生代码。

## 五、三个替代方案：均建议10分，待教师确认

下面只判断题目要求的入队、出队、判空与FIFO。没有已约定的效率要求，不因O(n)直接扣分；标准分支不适用时应映射到等效功能，不能机械要求每个方案都“检查两栈均空”。

### 011-000020：每次出队后还原S1

```text
1.入队：将元素进栈S1。
2.出队：将栈S1的栈顶元素一个个一次次入栈S2，直至S1只剩一个元素。出栈但不入S2，再将S2的栈顶元素依次入栈S1。
3.判断是否为空：判断S1是否为空即可。
```

所有待出队数据保留在S1，最早元素在栈底。移走栈底以上元素，弹出栈底，再倒回其余元素后，最早剩余元素仍在S1底部；S2在操作间隙为空。因此只判S1为空成立。入队O(1)，出队O(n)。

